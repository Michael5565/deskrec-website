Changelog

What's new in DeskRec. Updates install automatically on launch.

v0.1.2
Current — release builds embed the frontend
  • Added a custom protocol so release builds run the UI without a dev server.
  • More reliable distribution and updates.
v0.1.1
Polish & stability
  • Fixed an upside-down export bug in the renderer.
  • Added editor playback controls and interface tooltips.
  • Added pause / resume recording controls in the floating bar.
  • Fixed a duplicate Tailwind import that could break the dev server.
v0.1.0
Initial release
  • Windows screen recorder with automatic zoom, cursor smoothing and in-recording annotations.
  • Full screen, window and region capture sources.
  • System audio + microphone capture with device selection.
  • Floating webcam bubble and full-screen countdown overlay.
  • Distraction-free mode (auto-hide desktop icons).
  • Built-in editor with playback, timeline and MP4 export.
  • Speaker notes saved with every clip.
